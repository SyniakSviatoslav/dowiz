# Векторна навігація — ripgrep / fd / tsx

## Принцип
Заміна класичних grep/find/cat на векторну навігацію через:
- **ripgrep (rg)** — контент-пошук, швидший за grep, з відсіками по шляху і розширюваними фільтрами.
- **fd** — файловий пошук замість find, з інкрементальним читанням і фільтрами за типом/розширенням.
- **tsx** — виконання TypeScript/JavaScript без часу компіляції, замість cat/inline-run для скриптів.

## Маршрути
- `rg -n "pattern" kernel/src/` — пошук по коді ядра.
- `fd . kernel/src/` — перелік усіх файлів у ядрі.
- `fd -e rs kernel/src/` — тільки Rust-файли.
- `tsx script.ts` — запуск TS-скрипта без проміжних кроків.

## Інтеграція
Це не скрипти, а орієнтири для власної роботи: кожен наступний етап використовує ці інструменти замість старих команд.
