# The hub console, redesigned for clarity — 2026-09-26 (lane W-UX)

Operator brief: "переробити сучасно та якісно і найголовніше зрозуміло та красиво";
"усе має бути відразу видно, зручно оформлено і максимально просто"; "усе має мати ui
також усюди". Priorities in that order: **1 clear, 2 beautiful, 3 modern.**

Who uses it: the owner of a sushi restaurant in Durrës and their kitchen staff. A phone in
a kitchen (390 px, wet hands, one thumb), a tablet at the pass, a laptop in the office at
night. Three languages today (sq/en/uk), Russian coming, so nothing below assumes a word
is short. Mode (impeccable): **Operate** — the tool disappears into the task; brand lives
in precise details, never in decoration.

The console already had a good "contemporary pass" (Manrope, layers instead of boxes,
soft elevation, the design system in `/lib/ui`). This document does not replace that
world; it fixes what the screenshots show is still unclear, and it sets the rules so the
next screens (W-INV, W-QA, W-WIRE) land in the same shape.

Evidence: `scratchpad/shots/before/*.png` (390×844 and 1280×800, light and dark, every
screen and the main sheets, taken on the live hub 2026-09-26 20:12).

## 2. Principles (quote them before every decision)

1. **One heading per screen, and it names the screen.** No eyebrow over a title. The
   date, the count, the venue: a subline or the top bar, never a label above the heading.
2. **The first screenful is the work.** Orders: the queue starts above the fold. Menu and
   Stock: the first row is visible at 390 × 844 after one short toolbar.
3. **One primary action per screen, in the heading row.** Everything else is secondary
   or lives in the row it acts on. Buttons never overflow: an action row wraps.
4. **Rows, not tiles, for a map.** A settings map is a scannable list: icon, name, one
   line of what it holds, chevron. Groups are inset lists with a group name. A search
   above it finds any of them by name in any language.
5. **The desktop is a desktop.** From 1024 px the sidebar lists every destination
   (tabs, then the More groups), the content has a measure, and a sheet is a side panel.
6. **The person chooses the light.** Auto / light / dark in the preferences sheet,
   remembered per device.
7. **Status is one shape everywhere** (`.ui-status`): a hue dot, the word in ink on a
   soft tint. Danger colour is for the destructive act, not for a list's default button.
8. **Nothing tappable under 44 px; nothing that can be read under 12 px.** Inputs ≥16 px.
9. **Words are the surface's** (i18n keys, `data-t`); new words go in `admin/ux-i18n.js`
   and never assume three languages.
10. **Keep behaviour.** This is a redesign of presentation and information architecture.
    Every id, `data-*`, `data-tour` anchor and handler stays.

## 3. Information architecture and navigation

### 3.1 Phone and tablet (< 1024 px): the bottom bar, six tabs

`Porositë · Kuzhina · Menyja · Magazina · Korrierët · Lokali(More)` — unchanged set (a
staff member sees only the tabs their capabilities open). The More tab is renamed in
copy from "Tjetër / Other / Інше" to **"Lokali / Venue / Заклад"**: "Other" tells nobody
what is inside; the venue's own settings, people, numbers and marketing are what it holds.
(Hand-back: `tabMore` in `admin/i18n.js`, §8.)

Top bar: mark, venue name (fills the space), the venue's state chip (tap to change),
then the two "ask" controls (assistant, mic) and the profile button. **Sign-out leaves the
top bar on phones** — it is a once-a-month act sitting next to a many-times-a-day one — and
lives in the profile sheet (language, currency, appearance, sign out). The `#logout`
button stays in the header markup (its `header.logout` anchor and handler are unchanged)
and is shown from 720 px.

### 3.2 Desktop (≥ 1024 px): the sidebar is the whole map

The left sidebar carries the six tabs, then a hairline, then every More destination
grouped under its group name (Learn, Messages, Room, Marketing, Numbers, Settings), each a
single click that opens the same sheet the tile opens, as a side panel beside the content.
The current tab is the tinted pill; a sidebar entry that is open as a panel is marked
`aria-current="true"`. The More screen itself remains (it is the map on a phone), so
nothing is only reachable one way.

### 3.3 The More ("Lokali") screen: grouped rows and a search

Title "Lokali", a search field ("Kërko cilësim…") that filters every row by its title and
subline in the current language, then the groups as inset lists. Rows: icon in the
accent tint, title, one-line subtitle, chevron. On a tablet or desktop the groups flow
in two columns.

`localStorage.dw_theme` (`auto` removes the attribute). `lib/tokens.css` and
`admin.css` already honour `data-theme` in both directions; `theme-color` meta is
updated to match so the browser chrome follows.
