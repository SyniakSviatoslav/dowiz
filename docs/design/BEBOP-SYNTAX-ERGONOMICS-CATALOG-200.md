# BEBOP — Тотальний синтаксичний та ергономічний каталог: 200 рекомендацій

**Статус:** специфікація-беклог. 200 детальних рекомендацій щодо синтаксису, лексики, ергономіки, інструментарію та візуального стилю, у 10 доменах по 20.

## Домен 1: Лексика, гліфи та ASCII-дублери (1–20)
1. Мікро-символи (гліфи) для агентного потоку (⊗, ⊕, ↦) замість довгих ключових слів.
2. Повна відсутність крапок з комою (;) — жорстке позиційне перенесення рядків.
3. Двонаправлений лексер: гліфи та ASCII-аналоги парсяться однаково (-> для ↦, | для суперпозиції).
4. Мінімалістичні {} для блоків, замінені компактними відступами або символами меж арени.
5. `_` для анонімних лінійних змінних (знищення за QTT-рівнем 0).
6. Оператор `!` для форсованих ефектів без розгортання стека.
7. Компактні типи (u8, i32, f32) з префіксами розмірностей VSA (v1024).
8. Позначення арен префіксом `&` з індексом життя (наприклад `&a1` або `#1`).
9. Каррірування за замовчуванням через пробіл без круглих дужок для простих арів.
10. Оператор `=>` для pattern matching та ефект-роутів.
11. Коментарі: `//` для людей, блокові `/*@ ... @*/` для машинного опису семантики.
12. Відсутність `return` — остаточний вираз блоку автоматично стає результатом.
13. Нотації packed struct через квадратні дужки з вирівнюванням `[align 64]`.
14. Символ BIND ⨂ у гліфічному режимі, `*` у ASCII.
15. Символ PERMUTE ⟲ у векторному просторі.
16. Знак паралельності `||` для запуску корутин у зелених потоках.
17. Маркер чистоти функції (`pure`) на рівні модифікатора імені.
18. Оголошення контрактів блоком `where { ... }` перед тілом функції.
19. Відмова від null/nil: нульовий рівень лінійного типу покриває відсутність ресурсу.
20. Шрифтова незалежність: лігатури перетворюють ASCII-дублери у гліфи «на льоту».

25. Незмінність за замовчуванням (mut вимкнено).

27. Типізація гіпервекторів із розмірністю: `VSA<1024, f32>`.
28. Кастомні розмірності пам'яті packed struct у байтах.
29. Обмеження посилань усередині арен через зв'язки часу життя.
30. Модифікатори чистоти ефектів: `fn() -> io T` проти `fn() -> pure T`.
31. Псевдоніми типів: `type Id = u64`.
32. Сигнатури дженериків з префіксами роду типів.
33. Enum з можливістю векторних сутностей у варіантах.
34. Кортежі через круглі дужки без зайвих розділювачів.
35. Небезпечний доступ до масивів без перевірки меж: `[| i |]`.
36. Вбудовані масиви фіксованої довжини: `[T; N]`.
37. Вирівнювання даних: `#[align(64)]`.
38. Інтерфейси (трейти): `trait` + `impl`.
39. Делегування поведінки: `using`.
40. Інлайн-структури для локальних агрегацій.
